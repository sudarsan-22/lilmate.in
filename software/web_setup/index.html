Set up with Wi-Fi instead

This browser can't use Bluetooth. That's normal on iPhone. Use lil.mate's own Wi-Fi:

  1. Open Settings → Wi-Fi and join Lilmate-XXXX (the name is on lil.mate's screen).
  2. The setup page opens by itself. If it doesn't, open 192.168.4.1 in Safari.
  3. Pick your Wi-Fi, type the password, tap Connect.
  4. Switch your phone back to your usual Wi-Fi.

On Android or a computer? Open this page in Chrome or Edge for the Bluetooth way.

2. Pick your Wi-Fi

Only 2.4 GHz networks show up: lil.mate can't use 5 GHz ones (often named “…5G”).
